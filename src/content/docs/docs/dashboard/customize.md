Select **Customize** in the dashboard header to edit the current view.

## The editor

- The list shows every metric in the view, in order. The **first six** appear under **Key performance**; every metric after them appears under **Your metrics**, directly below.
- Move a metric up or down with the arrows, or remove it with **×**.
- **Add metrics** opens the metric library.
- **Create custom metric** builds your own formula (see [Custom metrics](/docs/dashboard/custom-metrics/)).
- **Templates** applies a ready-made layout.
- **Reset to default** restores Optifin's default layout.

The dashboard below previews your changes live. Select **Save** to keep them or **Cancel** to discard.

## Saved views and revisions

Use the view menu to switch between views (for example an owner view and a marketing view). Every save creates a new **revision**, so you can see how a view changed over time.
