Custom metrics let you track any ratio or combination of Optifin metrics.

## Create one

1. Select **Customize → Create custom metric**.
2. Enter a **Metric name**, for example *Marketing efficiency*.
3. Write the **Formula** using metric names and `+ − × ÷` and brackets, or select metrics from the list to insert them.
4. Choose the **Display format**: number, currency or percentage.
5. Check the **Preview**, calculated from the current dashboard range, then select **Create metric**.

If a field is missing, Optifin marks it in red and tells you what to fill in.

## Examples

| Name | Formula | Format |
|---|---|---|
| Profit per order | Net Profit / Orders | Currency |
| Discount share | Discounts / Gross Sales * 100 | Percentage |
| Ad cost per order | Total Ad Spend / Orders | Currency |

New custom metrics are added to the current view. Plan limits apply: 3 on Starter, 25 on Growth.
